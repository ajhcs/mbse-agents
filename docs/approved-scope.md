## Product direction

Build a leading systems engineering agent plugin: useful engineering reasoning,
understanding, explanation, investigation, design and review across substantial
systems and their lifecycle. Broaden the work and historical gallery. Codex,
Claude and Databricks are important host contexts; support claims must identify
what has actually been exercised. CSE supplies complementary computable analysis
and diagram methods; Ingenium informs editable presentation.

The user reports substantial downloads and inbound organizational interest.
This informs the product direction; it is not a verified usage count, customer
contract, endorsement, or permission to use an organization's marks.

## Evidence commitments

Strengthening a claim means supplying analysis, a justified model, an executable
experiment, or directly applicable source evidence. A Boolean proof establishes
the declared Boolean property. A simulation establishes behavior of the specified
model under its inputs. Neither silently becomes physical reliability, regulatory
approval, historical project evidence, or stakeholder acceptance.

The benchmark must test how an agent understands and communicates engineering,
not only whether it can invoke tools or reproduce expected vocabulary. Automatic
quiz scores, independently reviewed reasoning, artifact-task performance and
host activation are distinct results. Preserve failures and tune on development
cases; use fresh cases for subsequent assessment.

## Work streams

1. Agent reasoning, composition and domain contracts.
2. Domain simulation and evidence packages; historical engineering cases.
3. Judgment quizzes, project tasks, independent assessment and tuning.
4. Installation, recovery, host adaptation and portable plugin packaging.
5. Public documentation, editable source-derived diagrams and release evidence.

The release report records actual completed work and remaining gates against
these streams. No sales, subscription, telemetry, business-pilot or unrelated
maintenance-policy program is included.
