# Intended use and classification rationale

This is a teaching assumption, not a regulatory decision.

- Intended use: trained clinician programs IV fluids/medication for acute care.
  Local flow feedback maintains the selected delivery rate. No patient-physiology
  diagnostic loop is assumed to determine therapy automatically.
- U.S.: [21 CFR 880.5725](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-H/part-880/subpart-F/section-880.5725)
  identifies general infusion pumps as Class II. The former hemodialysis citation,
  876.5820, and generalized Class III/PMA conclusion were incorrect. Check product
  code, predicate, technology and indications before choosing the submission path.
  FDA's [TPLC guidance](https://www.fda.gov/media/78369/download), section 3,
  addresses Class II pumps and distinguishes pumps submitted as part of Class III systems.
- EU: provisional IIb under Rule 12 for potentially hazardous administration,
  supported by the examples in [MDCG 2021-24 Rev.1](https://health.ec.europa.eu/system/files/2021-10/mdcg_2021-24_en_0.pdf),
  Rule 12 table, printed page 48. Rule 11 concerns software; implementing rule 3.3
  addresses software driving/influencing a device. All applicable rules still need review.
- Software: IEC 62304 Class C is a separate teaching assumption from harm analysis.
  It is not derived from FDA or EU device class.
- Quality: [current 820.10(c)](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-H/part-820/subpart-A/section-820.10)
  and ISO 13485 design/development replace the old 820.30 clause structure.
  Historical FDA guidance may still use the old terminology.

Remaining decisions: exact product code/predicate, indications/population,
accessory/system boundary, automation, EU rule interaction, and software risk-control
classification rationale. No clearance, notified-body finding, or certification is claimed.
