# Test and Evaluation Master Plan (TEMP)

Record: **EVD-026**. System: **UAS Ground Control Station**. Lifecycle: **Drafted**. Configuration: versioned teaching document. Review: **not yet independently assessed**. Acceptance: **not granted**.

## Purpose and scope

This is a proposed engineering work plan for the teaching baseline. Applicability, lifecycle, assurance level, independence obligations and acceptance authority must be agreed for a real program before claiming compliance. No review gate or authority approval has occurred.

| Work package | Input and activity | Reviewable exit evidence |
| --- | --- | --- |
| Applicability and scope | Confirm intended use, boundary, operating modes, adopted editions and product configuration | Located source/applicability record and unresolved decisions |
| Development baseline | Reconcile requirements, functions, component allocation and interface contracts | Versioned draft with explicit assumptions and derived obligations |
| Failure and dependency analysis | Inspect shared power, clocks, data, tools and human dependencies; execute the supplied abstractions | Retained cut sets, scenarios, counterexamples and physical evidence gaps |
| Verification | Define stimuli, observations, pass conditions, uncertainty and configuration before execution | Procedure records plus immutable results, including failures |
| Review and change | Independent assessment of consequential findings; propagate changed obligations | Located dispositions and evidence applicability decisions |
| Acceptance | Evaluate the actual implemented system in representative conditions | Named authorised decision tied to configuration; currently open |

Role names describe proposed responsibilities only. Assign actual people, availability, independence and decision authority in the project. Software/hardware qualification and tool-credit decisions require the applicable program basis and actual use; this draft makes no qualification assertion.
