# Defense Examples

Reference systems demonstrating defense systems engineering artifacts for DoD acquisition programs. The flagship UAS GCS example includes DoDAF viewpoint products, MIL-STD-882E hazard analysis with risk acceptance authority chain, and DI-SESS deliverable mapping — all cross-referenced through a shared ID taxonomy.

| System | Tier | Key Standards | Artifacts |

| [Ballistic Missile Defense Element](ballistic-missile-defense/) | Fleet | DoDAF 2.02, MIL-STD-882E | Core: README, requirements, architecture |
| [Tactical SDR Radio](tactical-sdr-radio/) | Fleet | SCA 4.1, FACE 3.1 | Core: README, requirements, architecture |
| [Naval Combat Management System](naval-combat-management/) | Fleet | DoDAF 2.02, MIL-STD-882E | Core: README, requirements, architecture |

## What These Examples Demonstrate

- **UAS GCS flagship**: DoDAF OV/SV/DIV views with architecture traceability, MOSA/FACE layered architecture, MIL-STD-882E risk matrix with acceptance authority chain, DI-SESS CDRL mapping, SRR/PDR/CDR/TRR evidence gates
- **BMD**: System-of-systems boundary, positive fire control architecture, engagement authority chain
- **SDR radio**: SCA 4.1 waveform/platform separation, red/black crypto boundary, NSA Type 1 certification modes
- **Naval CMS**: Sensor-to-weapon kill chain, CEC integration, MIL-STD-1553 to GigE modernization, hardware weapon safety interlocks
