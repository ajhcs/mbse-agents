# Claude Desktop chat

Use the [portable guide](../generic/install.md) and the canonical packages in
`.agents/skills`. Verify the current host's skill/context mechanism before copying.
These are skills with local references, not legacy named subagent personas.
No supported discovery or invocation syntax for this host is asserted by this release.

For a local Claude Code session, use the maintained
[Claude Code plugin path](../claude-code/install.md). General chat and Cowork
have different installation surfaces; consult their available controls before
using a package. See the [support matrix](../support.md).
