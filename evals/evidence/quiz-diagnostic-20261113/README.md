# Initial quiz diagnostic, 2026-11-13

Three fresh participants answered the same 24 development questions using no
packaged skills, task skills, or task-plus-domain skills. All three selected
24/24 proposed keyed answers. This result exposed a ceiling and establishes no
benefit from the skills.

An independent reviewer found that selecting the longest answer, without
understanding the problem, succeeds on 54/55 single-choice questions across the
bank, including all 12 reserved-public questions. Two multiple-selection stems
also admit defensible alternative readings. This bank is unsuitable for a
comparative engineering-quality claim.

The [summary](summary.json), [surface-cue probe](choice-shortcuts.json), and
unchanged participant responses remain available: [no skills](none/answers.json),
[task skills](task/answers.json), and [task plus domain](task-domain/answers.json).
Their adjacent manifests, question packets and scores bind the recorded inputs.
The [original bank and scoring source](../../archive/benchmark-0.1.0/manifest.json)
are preserved before repairs. These schema1 scores are historical; the repaired
scorer uses a stricter input contract and does not retroactively validate them.

Participants were instructed to use only their packets. They shared a host that
exposed global skill descriptions, so this is not enforced isolation or a causal
estimate of skill effectiveness. Exact model identity/settings, tokens and cost
were unavailable. The reasoning text has not received independent scoring for
this retired-bank diagnostic.

The disposition is to repair question construction, packet/result binding and
review controls; retain this failure; use fresh participants for the revised
questions; and assess actual engineering work separately.
