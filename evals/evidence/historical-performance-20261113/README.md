# Connected historical project exercises

A separate participant completed three existing multi-file teaching projects:
[Mars Climate Orbiter](mars-climate-orbiter/outputs/decision-brief.md),
[Hubble optics](hubble-optics/outputs/decision-brief.md), and
[Heathrow Terminal 5](heathrow-terminal-5/outputs/decision-brief.md).
Each output includes proposed registers, editable relation views, a decision and
the observations that could change it. No physical or historical test was run.

The [independent review](../../../docs/evidence/reviews/historical-performance-review.md.txt)
rated each output 2 on all five assessed dimensions. It found no critical error
or required artifact correction. The reviewer disclosed its numeric anchors:
the frozen [protocol](protocol.json) named dimensions and critical errors but did
not predeclare a numeric scale. All 80 preparer-manifest entries, 83 recorded
input hashes, 25 output hashes and three record sidecars were checked.

Original register fields, IDs and evidence statuses remain preserved. The
[collection](collection.json) distinguishes participant input/output files from
reader references and public review guides added only after production.

Three cases share one participant context. Source retrieval and skill use are
self-reported and content-checked; native activation was not measured. These
observations support bounded artifact quality, not an improvement estimate,
historical counterfactual, original-project approval or engineering acceptance.
