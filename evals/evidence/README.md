# Observed skill-use evidence

The [revised quiz runs](quiz-0.2.0-20261114/README.md) scored 24/24 selections and
94/96 independently reviewed reasoning points in each arm. They expose a ceiling
and common reasoning gaps, with no observed advantage from adding the skills.

The [engineering task runs](performance-20261113/README.md) include 19 active
cases covering all 13 skills and five no-package comparisons. The
[connected historical exercises](historical-performance-20261113/README.md)
exercise three multi-file projects. A real outcome-rule ambiguity led to
[targeted guidance tuning and a fresh transfer check](verification-tuning-20261113/README.md).
Their independent agent assessments retain failures and comparison limits.

The [initial quiz diagnostic](quiz-diagnostic-20261113/README.md) preserves three
24-question runs. All arms reached 24/24; an independent surface-cue probe
invalidated the initial bank for comparative quality claims. Its failures and
original source remain recorded while the benchmark is repaired.

[HO-01](ho01/outputs/00-review-guide.md) is a single fresh artifact-producing
exercise using isolated requirements, architecture, and verification/evidence
packages. The producer had the raw request and packaged references, without the
worked answer or rubrics. Outputs and their original hashes are preserved.

A separate reviewer [assessed the actual artifacts](ho01/independent-assessment.md)
against the original facts and four proposed criteria, reproducing document checks
and all 12 trace mappings. No material repair remained for the requested draft.
Controller verification and stakeholder validation activities are planned, not executed.

[Run metadata](ho01/run-record.json) records unknown model identity/settings and
no external model API use. This is not a controlled Sol/Astra comparison or a pass
rate for the historical eight-case bank or the expanded current benchmark. Future behavioral claims need an authorized, recorded
host/model and additional unseen cases under the evaluation protocol.

The [judgment and performance benchmark](../../docs/benchmark.md) now provides
separate practice, development and reserved public evaluation questions plus
expanded artifact cases. Curated questions, answer keys, prepared packets and
synthetic scoring tests are evaluation infrastructure; they are not completed
agent runs. Add new run and independent-assessment links here only after their
artifacts and provenance exist.
